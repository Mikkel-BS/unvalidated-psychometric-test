How the scoring works

Each trait has six statements. Responses are scored 1–5; reverse-keyed statements are flipped. The mean is then rescaled to 0–100. A score of 50 therefore means the midpoint of the response scale, not “average compared with people.”

Every question and scale description in this project is original. The model borrows only broad, non-proprietary ideas from trait psychology.
